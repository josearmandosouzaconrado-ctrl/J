O que vamos descobrir hoje?

Funciono sem chave, com uma IA que roda no seu celular. Pesquiso na internet, YouTube, MyAnimeList e TVmaze, e crio jogos.

🎮 Seus jogos

Peça no chat: "crie um jogo de nave estilo arcade". O jogo aparece aqui. Toque em Jogar para testar e em APK para virar um app instalável (precisa do plugin do GitHub).

Para os melhores jogos use o Claude Fable 5.2 ou o Opus 5.5 (⚙ → Anthropic).

Pesquisas

Plugin: GitHub

Com um token, a IA lê e salva arquivos nos seus repositórios, abre issues e publica os APKs dos jogos. Crie em github.com → Settings → Developer settings → Personal access tokens → Fine-grained (permissão "Contents" e "Issues": leitura e escrita; para criar o repositório dos jogos, "Administration").

Plugins MCP (conectores; funcionam com o Claude)

Qualquer servidor MCP remoto: cole o endereço e o token. O Claude usa as ferramentas dele direto do servidor da Anthropic.
